## Layout & Sections

### Global Container

All sections share this container pattern:

```
max-w-6xl mx-auto px-screen
```

Sections stack vertically with `py-section` (64px) vertical padding each.

### Section Order

`app/page.tsx` composes:
1. `<Hero />` — full-width with watermark
2. `<Features />` — feature cards grid
3. `<Showcase />` — screenshot strip
4. `<Stats />` — stat tile row
5. `<Footer />` — global (inherited from Phase 1 layout, not in `page.tsx`)

### Hero Section

- **Layout:** Two-column on `md+` (`grid grid-cols-1 md:grid-cols-2 gap-xl items-center`), stacked on mobile
- **Left col:** `<h1>` (Display, emerald-600), `<p>` subheading (Body, navy-800/80), `<StoreBadges />` below
- **Right col:** Tilted iPhone mockup image (`rotate-3` or similar subtle tilt), `relative overflow-hidden`
- **Watermark:** Absolutely positioned top-right of Hero section container (`absolute top-0 right-0`), `<Image>` with `opacity-[0.06]`, no pointer events (`pointer-events-none`), width 320px height auto
- **Background:** `bg-cream` (page bg, no separate hero bg change needed)

### Features Section

- **Section header:** `<h2>` (Heading role, navy-800, `text-center mb-xl`)
- **Grid:** `grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-xl`
- **6 cards** (two rows of 3 on lg+)

### Showcase Section

- **Section header:** `<h2>` (Heading role, navy-800, `text-center mb-xl`)
- **Mobile:** `flex overflow-x-auto snap-x gap-md pb-sm` (scrollable strip, `-webkit-overflow-scrolling: touch`)
- **Desktop lg+:** `grid grid-cols-4 gap-md`
- **Each screenshot:** wrapped in a `<div>` phone-frame: `rounded-3xl border-4 border-navy-800/10 shadow-sm overflow-hidden`

### Stats Section

- **Layout:** `flex flex-wrap justify-center items-center gap-md` (wraps naturally on mobile)
- **Dividers:** gold-500 dot `·` rendered as `<span className="text-gold-500 select-none" aria-hidden="true">·</span>` between stat tiles
- **Each tile:** `<div className="text-center">`with Display number/word in `text-emerald-600` and optional Label caption in `text-navy-800/70`

## Interaction Contract

Inherits Phase 1 base: `hover:text-gold-500 transition-colors duration-fast` (150ms) on links.

| Interaction | Behaviour |
|-------------|-----------|
| Store badge hover | `opacity-90` at `duration-fast` (150ms) — subtle, no color distortion of official badge |
| Feature card hover | `border-gold-500/30 bg-surface-card-hover` at `duration-fast` (150ms) — no scale transform |
| Showcase strip (mobile) | `overflow-x-auto snap-x snap-mandatory` — native scroll, no JS carousel |
| Showcase strip scroll indicator | Rely on native scrollbar / momentum; no custom dots or arrows in Phase 2 |
| Hero image | Static; no hover animation |
| Watermark | `pointer-events-none` — no interaction |
| Nav links (inherited Footer) | `hover:text-gold-500 transition-colors duration-fast` |
