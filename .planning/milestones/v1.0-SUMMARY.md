# v1.0 — İkra Web Launch Milestone

**Status:** ✅ Complete · Shipped 2026-06-01
**Production:** https://ikra-web.vercel.app/

## What shipped

The marketing/landing site for İkra (Quran verses & Sahih hadith widget mobile app) is launch-ready for App Store and Google Play submission. Built greenfield in 4 phases over ~7 days.

### Key accomplishments

1. **Brand-accurate Next.js 16 + Tailwind v4 foundation** on Vercel with auto-deploy — emerald/gold/navy/cream palette ported verbatim from the mobile app's `tailwind.config.js`, Inter font, light-mode only (D-04), global Footer wired on every route.
2. **Full landing page** — Hero with locked reverent copy, 6-tile responsive Features grid with Lucide icons, 4-screenshot Showcase, 6-tile Stats row, all rendered through shadcn primitives where helpful.
3. **Store-submission-ready legal pages** — Privacy Policy (9 sections, all 8 third-party processors disclosed: Firebase Analytics/Crashlytics/Remote Config, RevenueCat, Apple/Google IAP, Expo Notifications, ATT, AppsFlyer, AdMob), Terms of Service (11 sections, Delaware governing law default), Support page (mailto + 5 FAQ open by default for SEO indexing).
4. **Full SEO surface** — per-page title via `%s — İkra` template, OG/Twitter meta, dynamic 1200×630 OG image via `next/og` with Inter Bold, sitemap.ts + robots.ts, canonical alternates, theme-color in viewport, application-name.
5. **CSS-only motion + responsive polish** — hero fade-in-up, feature card hover scale/ring, `prefers-reduced-motion` short-circuit with explicit opacity:1 + transform:none final state (no invisible-hero bug), `overflow-x-hidden` body safety net.
6. **17 requirements satisfied + 1 intentionally deferred** (UI-02 dark mode per D-04). Zero blockers in milestone audit. All 5 E2E flows pass on production.
